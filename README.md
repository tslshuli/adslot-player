# AdSlot Player

把视频「藏」进一个看起来像技术文档站点的页面里 —— 视频只占右下角或左下角一个不起眼的广告位，正文是一篇能在工位上说得过去的运维手册。

> 仅供个人学习与自用。是否使用、以及在什么场合使用，由使用者自行判断，请遵守所在单位的规定。

## 它解决什么问题

全屏看视频在工位上太扎眼。单纯把播放器缩小也没用 —— 整个屏幕只有那一处在动，反而更显眼。

这个项目换个思路：**先造一个像样的页面，再把视频塞进广告位**。

- 页面上有一篇 3000 字的运维手册，带代码块、表格
- 右侧栏和左下角是若干个「广告位」，其中一格在放你的视频
- 其余广告位放静音循环的视频背景，让「动的东西」不止一处
- 有人在旁边经过，看到的是一篇技术文档 + 几个广告

## 功能

| 能力 | 说明 |
|---|---|
| 多源视频 | 抖音直播、B 站直播、B 站视频、本地文件、任意 `.mp4` / `.flv` / `.m3u8` 直链 |
| **资源搜索** | `/` 键搜索全部 57 个 TVBox 资源站，点结果直接播放、自动连播 |
| **多集连播** | B 站分 P / 合集、gqc.ink 影视剧集、TVBox 搜索结果，自动播下一集 |
| **正文自定义** | `docs/` 目录放 md / html 即可；支持 docx / xlsx / pptx 导入；可抓任意网页正文 |
| 正文轮换 | 自动轮换 `docs/` 里的所有文档，默认 20 分钟一篇，`N` 键手动换 |
| 广告位伪装 | 视频藏在广告栏中，带「广告」角标和假关闭按钮 |
| 广告轮播 | 侧栏广告内容与配色定时轮换 |
| 隐蔽模式 | `i` 键压暗压灰，远看像静态插图 |
| 离开即隐藏 | 切走时广告栏消失、播放不中断 |
| 尺寸可调 | `[` `]` 缩放，`f` 临时放大看清 |

## 快速开始

环境要求：Node.js 18+，Windows / macOS / Linux

```bash
# 1. 启动本地服务（提供页面 + 转发视频流）
node live-server.js

# 2. 浏览器打开
http://127.0.0.1:8848/
```

Windows 用户可以直接双击 `启动伪装播放器.bat`。

> 必须通过 `http://` 打开，不能用 `file://`。flv.js 在 file 协议下会被 CORS 拦截。

## 接入视频

按 `L` 打开输入框，支持三种写法：

| 输入 | 说明 |
|---|---|
| `https://live.douyin.com/123456` | 抖音直播间，自动取流 |
| `https://live.bilibili.com/12345` | B 站直播间，自动取流 |
| `https://www.bilibili.com/video/BVxxxxxxxxxx` | B 站普通视频，720P 单文件 |
| `https://www.bilibili.com/video/BVxxx?p=3` | B 站分 P 视频，从第 3 P 开始 |
| `https://gqc.ink/bofang/12345-7-1.html` | 影视剧集页，自动连播全剧 |
| `https://example.com/xxx.m3u8` | 任意 HLS 流 |
| 直接把文件拖进页面 | 本地视频 |

流地址会过期，失效时按 `R` 重新获取。

### B 站多集连播

B 站的「系列」有两种，都支持自动连播：

- **分 P 视频**：一个 BV 号下 P1/P2/P3…，贴完整链接即可，支持 `?p=N` 指定从哪一集开始
- **UP 主合集 / 系列**：多个独立视频组成的合集，贴其中任意一集的链接

接入后左上角「广告」角标下方会出现一个很淡的 `3 / 100` 集数标记。一集播完会自动进入下一集，最后一集播完自动停。

切集有三种方式，挑顺手的用：

| 操作 | 方式 |
|---|---|
| 下一集 | **点一下左上角集数角标** · 或 `.` / `>` / `→` / `PageDown` |
| 上一集 | `Shift`+点角标 · 或 `,` / `<` / `←` / `PageUp` |

> 中文输入法下 `>` 会变成 `》`，已经兼容；但最稳的还是**直接点角标**，不受输入法影响。

切集会重新向 B 站取当前集的播放地址，所以不受原链接过期影响。`R` 刷新也会停在当前集，不会跳回第一集。

**切集没反应？** 按顺序排查：

1. 看左上角有没有 `▶ 1 / 378` 这样的角标。没有 → 是旧页面，按 `Ctrl + F5` 强制刷新；再不行就关掉黑窗口重新双击 `启动伪装播放器.bat`。
2. 有角标但按键没反应 → 刷新到最新版即可。旧版在刚输完链接、焦点还在输入框时会吞掉切集键；新版已修复，输入框里也能切，或直接点角标最稳妥。

> 番剧 / 正版连续剧通常需要大会员，取流接口有校验，暂不支持。

### 影视剧集页连播（gqc.ink）

贴 `gqc.ink` 的播放页链接（形如 `/bofang/数字-线路-集数.html`），会自动解析该线路的全部剧集并连播：

- 贴任意一集即可，从那一集开始播
- 每集的地址是实时解析的，不怕过期
- 链接里的 `-7-` 是线路号，不同线路画质/来源不同，换线路就改这个数字

> 这类站点服务器不稳定，偶尔会取流超时；遇到时按 `R` 重试即可。若某线路失效，换一条线路的数字再试。

### 资源搜索（TVBox）

按 **`/`** 打开搜索面板，输入片名，会并发搜索配置里的 **57 个资源站**并合并去重。

1. 输入片名 → 回车或点「搜索」
2. 点某个结果 → 显示它的全部分集
3. 点某一集 → 直接播放，播完自动下一集

特点：

- 一次搜遍所有站点，结果按站名标注来源
- 分集地址是现成直链，加密的 m3u8 也能正常播（本地服务自动改写并解密）
- 点角标或用 `.` / `,` 切集

> 搜索要并发请求 57 个站点，通常需要几秒。资源来自公开采集站，能否找到取决于站点当时的收录情况。配置源地址写死在 `live-server.js` 顶部的 `TVBOX_CONFIG`，换源改那里即可。

## 换正文

正文不写死在页面里，有三种来源，可以混着用。

### 1. 直接放文件（最简单）

往 `docs/` 里丢 `.md` 或 `.html`，刷新页面就会被纳入轮换。

文件名建议 `01-标题.md` 这种格式，前面的序号决定顺序，`01-` 后面的部分会显示为标题。

```markdown
# 标题

正文段落……

## 小节

- 列表项
- 列表项
```

`.md` 用内置的 marked 渲染，`.html` 直接插入（片段即可，不用写 `<html>` 标签）。

### 2. 导入 Office 文档

把 `.docx` / `.xlsx` / `.pptx` **拖到 `导入文档.bat` 上**，会自动转成 `docs/` 里的 html。

```bash
python tools/import-doc.py 手册.docx 数据.xlsx 汇报.pptx
```

支持范围：

| 格式 | 处理 |
|---|---|
| `.docx` | 段落、标题（Heading 1/2）、表格 |
| `.xlsx` | 第一个工作表，前 200 行，第一行当表头 |
| `.pptx` | 按页提取文本 |
| `.doc` / `.xls` / `.ppt` | 不支持，用 Office 另存为新格式 |
| `.pdf` | 不支持，建议先转 docx |

### 3. 抓网页

按 `L`，粘贴任意文章页链接，服务端会抓取并提取正文，加进轮换列表。

- 只提取文字、标题、列表、表格、代码块，样式全部丢弃
- 列表页、需要登录的页面会被拒绝并提示
- 抓不到正文时不会硬塞，会明确报错
- 抓来的内容默认只留在内存里，**刷新就没了**；想长期保留就再按 `S`，会存成 `docs/NN-标题.html`

### 用 AI 生成正文

任何 AI 生成的 markdown，存成 `docs/xx-标题.md` 就行。建议让它按「技术手册」的口吻写：分章节、带命令和表格、少用比喻，这样放在工位上更像手头正在处理的资料。

## 快捷键

`/` 资源搜索 · `L` 输入直播源 · `R` 刷新流 · `N` 换下一篇正文
`→` 快进 10 秒 · `←` 后退 10 秒（`Shift+→/←` 为 60 秒）
`.` 下一集 · `,` 上一集（多集时，也可 `PageUp/PageDown` 或点集数角标）
`[` `]` 缩放 · `\` 复位 · `f` 临时放大 · `h` 隐藏 · `i` 隐蔽滤镜
`a` 开关「离开即隐藏」· `m` 静音 · `空格` 暂停 · `Tab` 视频换广告位

## 工作原理

```
浏览器 ──> 本地 Node 服务 ──> 视频源 CDN / 任意网页
             │
             ├── /            静态页面
             ├── /resolve     解析直播间 / 视频页 → 直链
             ├── /tvbox       搜索资源站 / 拿分集列表
             ├── /proxy       转发视频流，补 Referer，处理 Range，改写 m3u8 相对路径
             ├── /docs-list   列出 docs/ 下的文档
             ├── /fetch       抓取网页正文
             └── /save-doc    把抓取内容存入 docs/
```

三个关键点：

1. **必须走本地代理**。视频站 CDN 有防盗链，直接在页面里请求会被 403。
2. **B 站直播要强制 H.264**。请求时加 `codec=0`，否则可能拿到 H.265，flv.js 解不了。
3. **B 站视频要不带 `fnval`**。带 `fnval=16` 会返回 DASH（音视频分离），单文件模式下才是可直接播放的 mp4。

## 目录

```
伪装播放器.html      单页应用（页面 + 全部交互）
live-server.js       本地服务：静态托管 + 取流 + 流转发 + 网页抓取
启动伪装播放器.bat    Windows 一键启动
导入文档.bat          把 Office 文档拖上去，转成可以轮换的正文
ads/                 广告位视频素材（程序生成）
docs/                正文文档，按文件名顺序轮换
tools/               素材生成 + 文档格式转换
libs/                marked.js / flv.js / hls.js 本地副本
```

## 自定义

**换广告素材**：把任意 mp4 丢进 `ads/`，刷新页面自动使用。文件名以 `ad_v_` 开头的优先分配给侧栏竖版位。

**重新生成广告视频**：

```bash
pip install pillow numpy imageio-ffmpeg
python tools/make-ad-videos.py
```

## 已知限制

- 腾讯视频 / 爱奇艺 / 优酷等站点有 DRM 加密，无法支持
- B 站付费、大会员专享视频取不到播放地址
- B 站分段视频（durl 多段）目前只播第一段
- 抖音流地址有效期通常几小时，过期需要按 `R` 重新取
- 网页抓取只读取服务端返回的 HTML，纯前端渲染的页面（SPA）可能抓不到正文
- 部分站点（如百家号）有安全验证，抓取会被拦截，需换来源或稍后再试

## 隐私说明

- 仓库内不含任何账号、密码、Token、私钥或个人身份信息。
- 两个 `.bat` 启动脚本通过 PATH / `%USERPROFILE%` 查找运行时，不写死本机用户名。
- 文档中出现的 `10.0.0.x` / `10.10.x.x` 均为 RFC 1918 内网保留地址，仅作示例。
- 服务只监听 `127.0.0.1`，不对外网开放；抓取网页时仅服务端请求目标站点，不上传本地数据。
- `.gitignore` 已排除本地记忆、凭据文件、截图与无关项目目录。
